# Curtain Opener
I've been obsessed with home automation lately. Ever since I used home assistant on an old laptop to control an LED strip ran around my bedroom. I've seeked to find new things to automate.
Then it hit me. I have a pull string curtain. What if I made a device that could pull that string for me to open my curtains? So that's what I set out to make.
